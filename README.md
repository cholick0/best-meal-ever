A make.fun entry: one sentence, at most 200 characters, about the best meal
I ever had — my grandmother's rendang in Padang.

`main.ts` writes the entry to `/output/entry.txt`, validating the gate
(1–200 characters, not only whitespace) before writing.

Run it with Node 22:

```sh
node main.ts
```
